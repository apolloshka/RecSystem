### Этап 0. Зафиксировать тему узко (1–2 дня)

Формула:  
**“Разработка и сравнение алгоритмов рекомендательной системы для [объекта] в социальной сети на основе [данных/сигналов], с оценкой по [метрикам] и улучшением за счёт [твоего вклада]”**

Примеры:

- “Рекомендация контента в ленте: collaborative + контентные признаки + reranking”
    
- “Рекомендация друзей: графовые эмбеддинги + GNN/Heuristics baseline”
    

### Этап 1. Обзор литературы и постановка задачи (1–2 недели)

Тут важно не “пересказать всё”, а:

- типы фидбэка (implicit/explicit),
    
- cold start,
    
- bias (popularity bias, echo chambers),
    
- offline vs online evaluation,
    
- подходы: popularity / content-based / MF / BPR / sequential / graph.
    

**Артефакт:** 8–15 страниц хорошего обзора + конкретная постановка.

### Этап 2. Данные и EDA (1–2 недели)

Выбираем датасет, делаем:

- описание сущностей (users/items/events),
    
- фильтрацию (минимум взаимодействий),
    
- временной сплит (train до T, test после T),
    
- статистики (длина сессий, распределение популярности).
    

**Артефакт:** воспроизводимый ноутбук/скрипт + таблички/графики в диплом.

### Этап 3. Бейзлайны (1–2 недели)

Обязательно сравнение:

- Popularity / Most recent
    
- ItemKNN или UserKNN
    
- Matrix Factorization (implicit ALS / BPR-MF)
    
- Простая content-based модель (TF-IDF/эмбеддинги + nearest neighbors) — если есть текст/описания
    

**Артефакт:** таблица метрик + выводы.

### Этап 4. Твой вклад (2–4 недели)

Варианты вкладов, которые реально сделать и хорошо защищать:

- **Гибридизация**: объединение collaborative и контентных скорингов (взвешивание, learning-to-rank)
    
- **Reranking с диверсификацией**: MMR, coverage, снижение повторов (очень “соцсетево”)
    
- **Cold-start стратегия**: для новых айтемов/юзеров
    
- **Сессии/последовательности**: GRU4Rec/SASRec-lite (если есть временные последовательности)
    
- **Графовый подход**: Node2Vec/LightGCN (если есть граф user–item или user–user)
    

Выбираем 1 основной вклад + 1 дополнительный “небольшой” (например, reranking).

### Этап 5. Оценка и честный протокол (1–2 недели)

Offline-метрики для top-k:

- Recall@K, NDCG@K, MAP@K
    
- Coverage, novelty, diversity (если делаешь rerank)
    
- Стабильность/значимость (bootstrap или хотя бы несколько random seeds)
    

Очень важно: **time-aware split**, иначе будет “утечка будущего”.

### Этап 6. Демонстрация (по желанию, 1–2 недели)

Мини-веб/streamlit:

- ввод юзера → топ рекомендаций → объяснение (почему)
    
- переключатель моделей
    

Это не обязаловка, но резко улучшает “вау-эффект”.

### Этап 7. Текст диплома (параллельно)

Лучше писать по мере готовности этапов: обзор → данные → методы → эксперименты → вывод.
